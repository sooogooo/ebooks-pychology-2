# 医美消费心理学

深度解析医美消费背后的心理机制与决策过程的学术电子书。

## 📖 关于本书

本书从心理学、哲学、社会学等多学科视角，系统性地探讨医美消费的心理机制，包括：

- **理论基础**：美学哲学、科学思维与身体智慧
- **社会镜像**：文化建构、数字自我与算法审美
- **内在世界**：人格特质、身体意象与心理健康
- **决策机制**：认知偏差、社会心理与理性选择
- **伦理思考**：个人自由与社会责任的平衡
- **未来展望**：技术革新对美学观念的影响
